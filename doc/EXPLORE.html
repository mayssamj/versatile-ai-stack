Status dot legend

gray = not checked (probing off) green = reachable (not necessarily healthy) amber = couldn't verify — amber is NOT "down" no dot = not a web service

Probing safety: Probing is OFF by default and only ever confirms reachability — it never reports a service as down, because browser CORS from a file:// page can block legitimate checks. A green dot means "something answered on that host:port", not that this exact service is healthy. Amber means "couldn't verify from here" — open the UI in-stack to confirm.
