Quickstart clean Mac → green doctor

Four commands. Everything runs local-only — no cloud keys required. Copy-run blocks work whether you opened this page from file:// or via the demo server.

1

Clone the repo onto a stable path (not /tmp) and enter it.

git clone <wherever-you-keep-it> ~/ai-stack && cd ~/ai-stack
2

Prepare the host — the one privileged, idempotent step (wires up name-based addressing in /etc/hosts + lo0). This is the only command that needs sudo.

sudo bash vz-ai-stack.sh prepare-sudo
3

Install the whole stack in order (resumes if interrupted). Run as your normal user — the installer refuses to run under sudo.

bash vz-ai-stack.sh install all
4

Verify you're healthy. Target: all checks green.

bash vz-ai-stack.sh doctor

The CLI entrypoint is always vz-ai-stack.sh. The bin/stack wrapper takes the same arguments (stack status, stack doctor, …) — use whichever you prefer.

Try it live safe in-browser demos, zero key in the page

Serve this page from the stack and the demo panels below light up — chatting real local models through a same-origin proxy.

bash vz-ai-stack.sh tutorial-serve

…then open the printed http://127.0.0.1:8899 in your browser.

Why this is safe. tutorial-serve mints a short-lived, local-only, budget-capped LiteLLM key and injects it server-side. Your browser never holds a token. The proxy is loopback-bound and exposes only a tiny allowlist — GET /api/health, GET /api/models, POST /api/chat — nothing else. The key auto-revokes when you stop the server, and live demos use local models only (free).
