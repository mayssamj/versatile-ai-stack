About this demo. Calls go directly from your browser to http://litellm:4000. If the page doesn't have permission (CORS), you'll see an error — that's expected and good (it means LiteLLM isn't accepting cross-origin calls by default). To use the live demo, either (a) open this HTML from a same-origin webserver (e.g., a local python -m http.server on the same host as LiteLLM), or (b) accept that the demo panel is illustrative and the same commands work from the terminal cheatsheet.

Triage when something breaks

Always start with doctor. The check number maps 1:1 to a section in DOCTOR.md.

Standard triage order

  1. Run doctor. bash ~/ai-stack/vz-ai-stack.sh doctor
  2. Read the matching DOCTOR.md section for whichever check failed.
  3. Tail the relevant logs. vz-ai-stack.sh logs <svc> -f
  4. Grep CHANGELOG.md for the service or symptom — known gotchas are documented.
  5. Look at TROUBLESHOOTING.md for less-common issues.
